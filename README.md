# Chatbot Using Pattern Matching

## Description

This project is a simple conversational chatbot built using Python and pattern matching techniques. The chatbot recognizes user intents through keyword mapping and provides appropriate responses.

## Features

* Keyword-based intent recognition
* Pattern matching responses
* Multiple conversation topics
* Fallback responses for unknown inputs
* Simple command-line interaction

## Technologies Used

* Python
* Regular Expressions (Regex)
* Basic NLP Concepts
